## クイックサマリー

**AI投資パートナー**は、投資初心者が「銘柄の選び方と読み解き方」を楽しく学べる学習プラットフォームです。

### 3つの主要機能

| 機能 | 概要 |
|------|------|
| **AI投資スタイル診断** | 9つの質問で8タイプに分類、個別化されたアドバイス |
| **デイリーニュースクイズ** | 毎日のニュースで投資判断力を鍛える |
| **学習ダッシュボード** | 経験値・レベルで成長を可視化 |

### 差別化ポイント

- **登録不要**で診断・クイズを体験可能
- **AIによる個別化**された診断結果
- **ゲーミフィケーション**で継続学習を促進
- **低コスト運用**でスケーラブル
