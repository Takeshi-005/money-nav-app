# アフィリエイト広告のPR表記ルール

景品表示法のステルスマーケティング規制（2023年10月〜）に対応するため、
アフィリエイトリンク・広告を掲載する際の「PR」表記ルールを定める。
本ルールは issue #20（リファラル導線実装）以降のすべての広告掲載で遵守する。

## 背景

- ステマ規制では、事業者の広告であるにもかかわらず、それが一般消費者に判別困難な表示は不当表示となる。
- アフィリエイトリンクは「事業者の表示」に該当し得るため、広告であることを明瞭に示す必要がある。
- 参照: [消費者庁 ステルスマーケティングに関する検討会](https://www.caa.go.jp/policies/policy/representation/fair_labeling/)
