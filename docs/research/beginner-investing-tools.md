## はじめに

### 想定読者

- **A. 投資未経験・口座未開設の人**：これから始める層。証券口座の選び方、用語学習、シミュレーションが中心。
- **B. 口座開設済み・少額運用中の人**：新NISA/iDeCo で運用開始済み。情報収集・ポートフォリオ管理・銘柄選定に踏み込みたい層。

### ツール選びの基本観点

| 観点 | 説明 |
|------|------|
| **コスト** | 無料 / フリーミアム / 有料。初心者は基本「無料 + 必要に応じて有料」で十分 |
| **UI/UX** | スマホ最適化・初心者向けの導線があるか |
| **情報量と一次情報性** | 二次まとめか、IR資料・適時開示・決算短信などの一次情報に辿れるか |
| **連携性** | 証券口座と自動連携できるか（取引履歴の自動取込） |
| **学習サポート** | 用語解説・チュートリアル・学習コンテンツの充実度 |
| **公的性・中立性** | 金融商品の販売目的でない、中立的な解説か |

## 7. AI系の新興ツール（参考枠）

2026年現在、**個人投資家の73.3%が生成AIを株式投資に活用**しているという調査結果（IDEATECH）が出ており、AI活用は既に主流。

### 汎用生成AIの使い分け（プロ推奨）

| AI | 得意領域 | 投資での主な使い方 |
|----|---------|------------------|
| **ChatGPT** | 推論・画像認識・データ分析 | 決算書の数値分析、CSV読み込み、スクリーニング条件の整理 |
| **Gemini** | Google検索連動・可視化・YouTube要約 | 最新ニュース調査、長期投資視点の銘柄分析 |
| **Claude** | 長文読解・ニュアンス把握 | 決算説明会の書き起こしから経営姿勢を読み取る |
| **Grok** | X連動・SNSセンチメント | ニュース化前の話題銘柄の温度感を拾う |
| **Perplexity / Genspark** | 出典明記の検索特化 | ハルシネーション対策・ファクトチェック |

### AI特化型投資サービス

- **moomoo AI** — moomoo証券のAIアシスタント（米国株の精度に定評）
- **AI投資パートナー（本プロジェクト）** — 投資初心者向け学習支援、診断・クイズ・ニュース解説
- 各証券会社のAIニュース要約機能（SBI、楽天など順次拡充）

### AI活用時の必須リテラシー

1. **ハルシネーション対策**：出典リンクを必ず確認、複数AIでクロスチェック
2. **個人情報の匿名化**：資産額は「約1000万円」のように丸める、銘柄は「半導体A銘柄」のように匿名化
3. **学習機能のオフ**：ChatGPTなら設定→データコントロールで学習機能をオフ
4. **AI予測の限界**：個別銘柄予測精度はコイン投げ並み（フロリダ大学研究）と認識する
5. **一次情報との照合**：AI回答者の64.3%しか一次情報と照合していない現状を踏まえ、自分は必ず照合する

## 注意事項

1. **投資助言ではない**：本ドキュメントは一般的なツールカタログ。最終判断は自己責任。
2. **情報の鮮度**：2026年5月時点。手数料・サービス内容・税制は変わるため、行動前に必ず公式サイトを確認。
3. **NISA は1人1口座**：金融機関変更は年単位で可能だが、頻繁な変更は手間が大きい。最初の選択を慎重に。
4. **AI は万能ではない**：個別株予測の精度は約51%（ほぼコイン投げ）。あくまでセカンドオピニオン。
5. **税制改正**：新NISA・iDeCo の制度は年度で見直しがあるため、金融庁公式情報を確認。
6. **一次情報主義**：二次情報のまとめサイトに頼らず、必ず TDnet/EDINET/企業IR の一次情報まで辿る習慣を。
