# 4コマ漫画コンテンツ キャラクター設定ドキュメント

## 目的

投資初心者向けの4コマ漫画コンテンツに登場する3人のキャラクター設定を、AI生成プロンプトの定数として機能する粒度まで定義したドキュメントです。

**用途**:
- AI生成プロンプト（ストーリー構成・セリフ・画像）の入力定数
- Judge（生成品質検証）の口調・キャラ一貫性チェック基準
- 表情ライブラリ（keyframes）の事前生成仕様書
- 編集者・運用担当者がキャラ世界観を維持するためのリファレンス

**コンテンツの方針（前提）**:
- 主目的: **SEO強化（流入増）+ 継続学習（DAU向上）**
- テーマ配分: 体系9割（NISA / 暴落心理 / 積立 等）× 時事1割
- 配信先: Web先行（後にX連携）
- トーン: ガチ解説NG、ゆる日常系・共感系・失敗あるある系
- 1コマあたりセリフ10〜20文字、最大2行

## キャラクター3: 解説役「田島ヒロシ」

### 基本プロファイル

| 項目 | 設定 |
|------|------|
| 名前 | 田島ヒロシ（たじま ひろし） |
| 年齢 | 42歳 |
| 職業 | 経理部主任、ユキの2階級上の先輩 |
| 資格 | FP2級、簿記1級 |
| 投資経験 | 15年(リーマンショック・コロナショック経験者) |
| 家族 | 妻と娘1人、住宅ローン返済中 |

### 性格・価値観（クセを意図的に作る）

- **コア特性**: 理屈っぽい・例え話が独特・他人に興味ない風で実は世話焼き
- **クセ**: **何でも比喩で語る**。比喩源は **テーマに最適なもの** をその都度選択する（コーヒー、写真、通勤、料理、経理、家族、ガーデニング、筋トレ、マラソンなど）。**読者の理解しやすさが最優先**
- **ビジュアルブランド**: 常に **コーヒーマグを持っている**（コーヒー好きという視覚的アイデンティティはセリフと独立して維持）
- **強み**: 知識量と経験値・冷静・データ重視・複数領域の引き出し（FP/経理/家族経験）
- **弱み**: 説明が長くなる・例えがわかりにくいときがある・趣味の話より仕事と日常の例えに偏る

### 物語上の役割

- 解説役だが「正解を押し付けない」スタンス
- ユキとアヤの会話に **割り込んでくる形** で登場（教科書臭さを消す）
- ときどき自分の過去の失敗を語る（権威性ではなく人間性を出す）

### 口調・口癖（Judge検証用）

- **基本**: 落ち着いた敬語、若干まどろっこしい
- **特徴的フレーズ**:
  - 「ふむ…それはね、つまり…」
  - 「コーヒーで言うと…」（メイン、6〜7割の話で使用）
  - 「通勤で言うと…」「料理で言うと…」「経理で言うと…」「うちの娘がね…」（補助、テーマに応じて選択）
  - 「逆に言えば、ですよ」
  - 「私も昔、同じこと考えてました」
  - 「焦らないで、まず深呼吸」
- **必須要素**: 1話につき必ず1つの比喩源シグネチャフレーズ（「○○で言うと…」等）を使う
- **NG表現**: 若者言葉、断定的な投資推奨、「絶対」「必ず」

### 比喩源マッピング（テーマ最適主軸）

田島さんはテーマに応じて最も伝わりやすい比喩源を選ぶ。**比喩源の縛りはなく、読者の理解しやすさが最優先**。以下は推奨マッピングであって絶対ではない。

| 投資テーマ | 推奨比喩源 | シグネチャフレーズ例 |
|-----------|----------|-------------------|
| 長期投資・複利 | コーヒー（抽出/焙煎）、ガーデニング | 「コーヒーで言うと…」「ガーデニングで言うと…」 |
| 積立継続・習慣化 | 通勤、歯磨き、筋トレ | 「通勤で言うと…」「筋トレで言うと…」 |
| 暴落・リスク | コーヒー（豆セール）、マラソン、天気 | 「コーヒーで言うと…」「マラソンで言うと…」 |
| 分散投資 | 料理（レシピ）、お弁当 | 「料理で言うと…」「お弁当で言うと…」 |
| 制度理解（NISA等） | コーヒー（マグカップ）、容器、弁当箱 | 「コーヒーで言うと…」 |
| SNS比較・心理 | **写真**、ファッション | 「写真で言うと…」 |
| 計算・固定費・税金 | 経理、数字 | 「経理で言うと…」「数字で言うと…」 |
| ライフプラン | 家族、娘 | 「うちの娘がね…」「家族で言うと…」 |

**重要原則**:
- **比喩源は「テーマに最適なもの」を選ぶ**（コーヒー縛りなし、無理に当てはめない）
- **ビジュアルアイコンとしてのコーヒーマグは常に維持**（コーヒー好きという視覚的キャラ性は保持）
- **どの比喩源でも「逆説/問いかけ/例え話/暴露」の解説スタイル**は不変
- **同一話の中では1つの比喩源に統一**（写真と通勤を混ぜない）
- **シグネチャ「○○で言うと…」または「うちの娘」型を必ず使う**（バリデータで機械検出）
- **「コーヒーで言うと…」を使う時は後続にコーヒー要素（豆/マグ/抽出等）を含める**（バリデータで強制）

### コーヒー例えの具体例（メイン軸、プロンプト用ストック）

| 投資概念 | コーヒー例え |
|---------|------------|
| 積立NISA | 「毎日一杯コーヒー飲むのが積立NISA。たまに豆を変えるのが銘柄リバランス」 |
| 複利 | 「焙煎したての豆が時間と共に風味を増すように」 |
| 暴落 | 「冷めたコーヒーも温め直せば飲める」 |
| 分散投資 | 「ブレンドコーヒーがリスク分散」 |
| インデックス投資 | 「セブンのコーヒー、毎日同じ味なのが強さ」 |
| 短期売買 | 「淹れたてを飲まずに何度も淹れ直す人」 |
| ドルコスト平均法 | 「毎日同じ時間に同じ量を淹れる習慣」 |

## キャラ関係性マップ

```
        ┌─ 押す役 ──┐
   ユキ ←───────── アヤ
    ↑                ↑
    │ 不安           │ 半端な知識
    │                │
    └── 田島さん ────┘
          ↓
       コーヒー
       片手に解説
```

### 会話のテンプレ動線（4コマ漫画の基本パターン）

1. **コマ1**: ユキが不安を表明（例:「新NISAって何から始めれば…」）
2. **コマ2**: アヤが浅い知識でアドバイス（例:「インフルエンサーが個別株から始めろって！」）
3. **コマ3**: 田島さんが割り込み、コーヒー例えで本質を説明
4. **コマ4**: ユキが納得 or 行動の決意（オチ）

→ **「3人いることで教科書臭くならない」** のがこの構成の肝。アヤの半端知識が田島さんの解説の必然性を作っている。

### 4コマ構成パターン（バリエーション）

- **パターンA（悩み解消型）**: 不安 → 誤解 → 気付き → 腑に落ちる
- **パターンB（SNS比較型）**: SNSで爆益を見る → 落ち込む → 現実を知る → 自分の積立を肯定
- **パターンC（暴落動揺型）**: パニック → 解約しようとする → 解説役が止める → 成長を示す

## 設計上の重要な意図（運用者・編集者向け）

### 1. アヤの「半端知識ボケ役」が設計の核心

解説役の田島さんだけだとどうしても教科書化する。間にボケるアヤがいることで「読者代弁」と「解説の必然性」を同時に成立させる。漫才の「ボケ・ツッコミ・解説」三段構造と同じ。

### 2. 田島さんの「比喩クセ」と「コーヒーマグ」の役割分担

田島さんは **「比喩で語る先輩」** がキャラの本質。比喩源は**テーマ最適性で都度選ぶ**（コーヒー縛りなし）。読者の理解しやすさを犠牲にしてまでブランディングを優先しない、という設計原則を採用している。

その代わり、**コーヒーマグを常に持つ** というビジュアルブランドはセリフから独立して維持。これにより「コーヒー好きな先輩」というキャラの記号性は視覚的に保ちつつ、セリフは **読者にとって最も伝わりやすい比喩** で構成できる。

| 要素 | 制約 |
|------|------|
| セリフの比喩源 | **完全自由**（テーマ最適性で選択） |
| ビジュアル（持ち物） | **必ずコーヒーマグ**（不変のブランドアイコン） |
| セリフのシグネチャ | **「○○で言うと」または「うちの娘」必須**（バリデータで強制） |
| コーヒー比喩使用時 | 後続にコーヒー要素（豆/マグ/抽出等）必須（バリデータで強制） |

この **「セリフは可変、ビジュアルは不変」** の設計により、長期連載でも読者の理解と田島さんの記号性が両立する。

### 3. キャラ年齢差（24歳×2 + 42歳）は意図的

読者主層（20代）の代弁者が2人いて、上司役が1人。これがあると「親近感」と「権威性」が両立し、SEO的にも「初心者向け」と「専門性」の両方のキーワードを自然に拾える。

### 4. ビジュアルの「シンプル原則」は不可侵

- 色数限定（4色程度）
- アクセサリーなし
- 髪型・服装の特徴を固定
- 影なし、線細め

これらを崩すとAI生成のキャラ一貫性が即崩壊する。デザインを「凝りたい」誘惑に負けないこと。
