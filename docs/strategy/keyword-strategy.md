# テーマ・キーワード戦略（月10万円ロードマップ）

作成日: 2026-06-27
収益モデル: 証券口座開設アフィリエイト（主）＋ AdSense（従）

---

## 0. 結論サマリー

- 月10万円の主役は **AdSense ではなく証券口座開設アフィリエイト**。AdSense単独で10万円は月20〜40万PV級が必要で、新規ドメインには非現実的。
- 必要な口座開設は **月10件前後**（1件あたり報酬を約1万円と仮定）。つまり「大量のPV」より「換金できる読者を少数でも口座開設まで運ぶ設計」が先。
- キーワードは **2階建て**で設計する。
  - **1階（集客KW）**: 検索ボリュームがあり、AdSense収益とドメイン評価を稼ぐ。大手と正面衝突しないロングテール中心。
  - **2階（換金KW）**: 「口座開設」「証券会社 比較」など購買意欲の高い語。1階から内部リンクで送客する。
- あなたのサイトの**独自資産（適時開示分析・診断・ニュース解説）を、大手が手を出さないニッチKWに変換する**のが唯一現実的な勝ち筋。

> 注: 本書の検索ボリューム表記は「相対的な目安（大/中/小）」です。正確な数値は Google キーワードプランナー / ラッコキーワード / Search Console の実データで都度確認してください。

## 1. なぜ今、集客が伸びないのか（構造的な理由）

「投資 初心者」「株 始め方」「証券会社 おすすめ」のようなビッグKWは、検索結果を以下が独占している：

- 証券会社の公式メディア（楽天証券トウシル、SBI、マネックスの学習コンテンツ）
- 大手金融メディア（みんかぶ、ザイ・オンライン、MONEY PLUS 等）
- 銀行・保険・比較サイト（価格.com、moneyforward 等）

これらは**ドメインパワー・被リンク・運営年数**で圧倒的に有利。新規個人サイトが同じKWで戦うのは、徒競走で100m後ろからスタートするようなもの。**「正面で勝つ」発想を捨て、相手がいない場所で1位を取る**のが前提。

## 2. 2階建てキーワード設計

### 2階：換金キーワード（少数・高単価／口座開設に直結）

口座開設アフィリエイトのコンバージョンが発生するのはここ。サイトに**この記事群が無い、または弱い**なら最優先で作る。

| キーワード例 | 検索意図 | 競合 | 役割 |
|---|---|---|---|
| 証券会社 初心者 おすすめ 比較 | 口座を作る直前 | 高 | 最重要・本命 |
| SBI証券 楽天証券 どっち | 2社で迷っている | 中 | 比較記事の鉄板 |
| NISA 口座 開設 やり方 初心者 | 制度きっかけで開設 | 中高 | 制度×開設 |
| 単元未満株 始め方 おすすめ証券 | 少額で始めたい層 | 中 | あなたの初心者層と相性◎ |
| ◯◯証券 口座開設 キャンペーン | 開設一歩手前 | 中 | 時期性で更新し続ける |

ポイント:
- これらは**ボリュームが小さくても良い**。月数百検索でも、購買意欲が極端に高いので少PVで口座開設が出る。
- 比較記事には必ず**結論（あなたのおすすめ1〜2社）と理由**を明記。中立に並べるだけの記事は1円も生まない。
- 各証券会社の**正規アフィリエイトプログラム（A8.net / もしもアフィリエイト / バリューコマース等）**に登録し、ASIN的に正しいリンクを貼ること。

### 1階：集客キーワード（多数・低単価／AdSense＋送客）

ここで人を集め、上の2階記事へ内部リンクで流す。**あなたの独自機能をそのままKW化**するのが差別化の核。

#### A. 適時開示・好悪材料系（最大の差別化ポイント・大手が手薄）

`tomorrow-impact` / `disclosures` 機能が独自に強い領域。大手メディアは「個別の開示を初心者向けに噛み砕く」ことをほぼやっていない。

- 「適時開示 とは 初心者」「適時開示 見方」
- 「自己株式取得 株価 影響 なぜ上がる」
- 「上方修正 株価 影響」「下方修正 株価 下がる理由」
- 「株式分割 メリット 初心者」
- 「決算 好材料 悪材料 見分け方」

→ これらは「用語×影響×なぜ」の型で量産でき、検索意図が明確で、かつ**投資を始めたい人**が読む＝2階の口座開設記事に送りやすい。

#### B. 投資スタイル診断系（指名・話題性・SNS拡散）

診断コンテンツはSNS（X）でシェアされやすく、被リンク・指名検索を生む。

- 「投資 タイプ 診断」「自分に合う投資スタイル 診断」
- 「リスク許容度 診断 投資」
- 8タイプそれぞれを記事化（例: 「◯◯型 投資家 特徴 向いている投資」）

→ 診断結果ページの末尾に「あなたのタイプにおすすめの証券口座」導線を置く（＝2階へ接続）。

#### C. 用語・なぜ系（ロングテールの土台）

- 「PER とは 初心者 わかりやすく」「ROE 目安」「配当利回り 計算」
- 「ストップ高 とは」「日経平均 とは 簡単に」

→ ボリュームは取れるが競合も多い。**数で勝負せず、Bと組み合わせて内部リンクのハブ**にする。

## 3. コンテンツの「型」テンプレート

量産時にブレないよう、記事の型を固定する。

**換金記事（2階）の型**
1. 結論（おすすめ証券会社）を冒頭で明言
2. なぜ初心者にそれが向くか（手数料・少額・アプリの分かりやすさ）
3. 比較表
4. 口座開設の手順（スクショ）
5. CTA（アフィリエイトリンク）を本文中に2〜3回

**集客記事（1階）の型**
1. 検索意図への即答（最初の3行で答える＝SEOで超重要）
2. 図解・具体例
3. 関連する「次の一歩」へ内部リンク（最終的に2階へ）

## 4. 90日アクションプラン

### Phase 1（1〜30日）: 換金の土台を作る
- A8.net / もしもアフィリエイト等に登録、主要証券のプログラム提携
- 2階の本命記事を3本作成（「証券会社 初心者 比較」「SBI vs 楽天」「NISA 開設手順」）
- 既存の診断・ニュース解説の末尾に口座開設CTAを設置（導線接続）
- Search Console でインデックス状況・サイトマップ送信を確認

### Phase 2（31〜60日）: 独自KWで集客を積む
- 適時開示・好悪材料系を週2本ペースで10本（差別化の核）
- 各記事から2階の本命記事へ内部リンク
- 8タイプ診断の個別記事化＋Xでの診断シェア導線

### Phase 3（61〜90日）: 計測して回す
- Search Console で「表示はされるがクリックされないKW」を抽出 → タイトル改善
- CTR・口座開設の発生箇所を計測し、勝ちパターンを横展開
- AdSense配置の最適化（記事下・目次後）

## 5. 計測（これをやらないと改善できない）

- **Search Console**: インデックス数 / クエリ別表示回数・CTR / 平均掲載順位
- **GA4**: 流入元別の口座開設CTAクリック / 記事別の離脱
- **アフィリエイトASP管理画面**: クリック数・成果数（最終KPI）

> このリポジトリには Search Console / GA4 を点検するスキルがあるので、実データでの定期診断を Phase 3 で回すと精度が上がります。

---

## 6. やってはいけないこと

- ビッグKW（「投資 初心者」単体など）で大手に正面から挑む
- 換金導線のない「ただ良い記事」を量産する（PVが出ても10万円に繋がらない）
- 中立に並べるだけの比較記事（結論を出さない記事はコンバージョンしない）
- AdSense単独で10万円を狙う（必要PVが非現実的）
