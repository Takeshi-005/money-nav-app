# X（Twitter）運用方針

訪問者ゼロの主因の1つ「SEO以外のチャネルがゼロ」を埋めるための、X 運用プレイブック。SEO が数ヶ月の複利施策で今週の流入を生まないのに対し、**X は今週流入を生める唯一のレバー**。指名検索（`マネイッポ 診断` 等）は X で認知を作った後に育つため、X が本丸・指名検索は仕込み、という役割分担で運用する。

関連: [収益化ロードマップ Epic #24](https://github.com/Takeshi-005/kabu-news-ai/issues/24)（本運用は「収益化P1: 流入の下地」に相当）

## 前提と目標

- **0フォロワー期のKPIは「フォロワー数」ではなく「信頼の在庫」**（＝損も出した誠実な投稿の蓄積数）。フォロワー数は初期ほぼ動かず挫折要因になるため指標にしない。
- 0フォロワーの「配信」は誰にも届かない（初期リーチはフォロワー数に依存）。成長の初速は**配信ではなく「会話への参加（リプライ/引用）＝借りたリーチ」**から生まれる。
- 最大の差別化資産は**運営者の一次情報（実際の売買・配当・失敗）**。大手やAIが出せない唯一の一次情報で、これを"顔"にする。

## 信頼設計（投資領域は「疑われている」ところから始まる）

投資系は詐欺・情報商材が多く、新規アカウントは初期状態が「怪しい」。信頼は「誠実です」と主張しても生まれず、**詐欺アカウントが絶対にやらないことを先回りして明示する**ことでコントラストとして立ち上がる。幸いこの逆張りはサービスの核・`/about` の姿勢と一致しており、X と揃えること自体が一貫性＝信頼シグナルになる。

| 詐欺・情報商材の典型 | マネイッポが明示する逆張り |
| --- | --- |
| 「絶対儲かる」「この銘柄が上がる」 | 銘柄は推奨しない（判断力を養う教育サービス） |
| LINE登録・有料サロン・情報商材へ誘導 | 完全無料・勧誘なし・リンクは1本だけ |
| 成功だけ見せる | 失敗・損失も等身大で出す |
| 断定・射幸心を煽る | 自己責任・投資助言ではないと明記 |

## プロフィールと固定ツイート（Day 0・一度きり）

- **表示名**: マネイッポ
- **bio**: 投資の最初の一歩を伴走｜銘柄推奨なし・完全無料｜初心者向け（＋サイトURL）
- **固定ツイート（信頼設計版）**:

```
「絶対儲かる」「この銘柄が上がる」は一切言いません。

マネイッポは銘柄を推奨せず、"自分で判断する力"を育てる無料の学習サービス。情報商材や有料サロンへの勧誘もなし。

運営者も個人投資家。失敗も含め等身大で発信します👇
https://money-nav.com/diagnosis?utm_source=x&utm_medium=social&utm_campaign=profile_pin
※投資は自己責任でお願いします
```

冒頭で「詐欺がよく使う殺し文句」を否定から入るのが肝。読み手の警戒を最初の1行で解除する。

## 毎日のルーティン（15分）

```
10分: 一次情報を1本（信頼シグナルを織り込む）
   曜日ローテ例:
     月 今日の売買と判断理由     木 初心者がつまずく点をやさしく解説
     火 含み損・失敗と学び        金 1週間の振り返り
     水 配当・実績の等身大報告
   ★週2回は必ず「損・失敗・迷い」を出す（＝詐欺払拭の主力弾）
 5分: 関連会話に1〜2リプライ（新NISA / 積立 / 初心者の悩み）
   売り込まず、当事者として価値提供のみ
```

自動生成の日次ニュース・好悪材料（Slack下書き経由）は**継続するが「量」担当の従**。単体では伸びない前提で、運営者の一次情報を主役にする。

### 一次情報の投稿テンプレ（叩き台）

```
【今日の判断】〇〇を△株買い増し。理由は□□。
初心者の頃の自分なら「上がってるから怖い」で見送ってた。
でも◇◇を学んでからは〜と考えられるように。
※投資は自己責任・助言ではありません
```

## 週末のレビュー（10分）

- GA4「x / social」＋ UTM（`utm_campaign=profile_pin` 等）で診断への流入を確認
- 反応が良かった投稿の"型"を1行メモし、翌週に再利用

## やらないこと（信頼を壊す禁止事項）

- 「絶対儲かる」「この銘柄が上がる」の煽り・断定
- LINE誘導・有料サロン・情報商材への導線
- 成功だけの誇張、フォロワー買い

## X 固有の制約メモ

- 文字数上限280は**日本語が2倍重み**（実質約140字）。URLは実長に関わらず23固定。
- 固定ツイートにはハッシュタグを付けない（"顔"なので雑味を消す）。日次投稿のハッシュタグは `#株式投資` 等の汎用タグを使用（コード側の下書き生成に準拠）。
- 投稿文中のURLには UTM を付与して GA4 で流入を分離計測（コードの `withXUtmParams` と同方針）。
